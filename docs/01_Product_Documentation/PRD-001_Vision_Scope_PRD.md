# Product Vision & Scope
Build an autonomous, zero-ban-risk AI Job Application Autopilot ("AutoApply-AI") that discovers high-fit software/AI engineering roles within 15 minutes of posting, dynamically compiles a tailored LaTeX PDF resume per role, executes multi-step applications via stealth local browser agents, and escalates low-confidence questions or OTP challenges to the user's phone via Telegram for 1-tap human-in-the-loop (HITL) resolution.
